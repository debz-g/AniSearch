# AniSearch

AniSearch is a modern anime discovery app that helps you find, track, and enjoy your favorite anime series. With an intuitive interface and comprehensive features, AniSearch makes it easy to explore new shows and stay updated on airing schedules.

## Features

### Current Features
- **Explore Section**: Discover new and trending anime titles based on genres, seasons, and popularity
- **Schedule Section**: Stay updated with airing schedules organized by day of the week

### Coming Soon
- **Profile Section**: Connect with popular anime tracking platforms to manage your watchlist
- **Manga Section**: Browse and discover manga with detailed information and recommendations

## Technology Stack

### App
- Kotlin
- XML
- MVVM Architecture
- RecyclerViews with DiffUtil
- LiveData and Flows
- ViewModel
- ViewBinding
- TOML library management

### Backend
- Jikan V4 API
